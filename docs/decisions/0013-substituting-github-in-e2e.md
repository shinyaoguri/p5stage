# 0013: E2E では GitHub の宛先を差し替える (受け付けるのはループバックだけ)

## 状態

採用 (2026-08-13)

## 文脈

Phase 2-7。Phase 2 の完了条件は「ログイン → 作成 → 保存 (Gist リビジョン) →
別ブラウザの作品ページで閲覧」だが、**その通しを一度も踏めていない**。

2-1 以降に書いた E2E はどれも「ログインが要る操作は GitHub の認可が要り、E2E では
踏めない」と書いて、認可の**手前**と守り (401 / 403) だけを見ている。作品ページ
(2-4) だけは D1 と R2 に種を蒔いて配信経路を踏ませたが、**保存の経路 (Gist の
create / PATCH → D1 → R2) は実ブラウザで一度も動いていない**。Phase 2 で壊れると
いちばん痛いのがそこで、単体テストからは Worker のルーティングも cookie の実挙動も
見えない。

踏めない理由は 1 つ。**GitHub を叩くのは Worker (サーバ) である** (ADR 0010)。
ブラウザ側の仕掛け (Playwright の `page.route`) では捕まえられない。セッションを
D1 に直に蒔いてログイン状態を作る手もあるが、その先の保存で結局 GitHub へ出ていく。

## 決定

### 1. GitHub の宛先を設定で差し替えられるようにする

`lib/github/origins.ts` に既定 (`https://api.github.com` / `https://github.com`) を
置き、`GITHUB_TEST_ORIGIN` があればそちらを使う。E2E は偽 GitHub
(`e2e/fake-github/server.ts`) を立て、`wrangler dev --var` でそこへ向ける。

差し替わるのは**宛先だけ**。認可コードの往復も `state` の検証も `__Host-` cookie の
発行も、本物と同じ経路をそのまま通る。

### 2. 受け付けるのはループバックの宛先だけ

`localhost` / `127.0.0.1` / `[::1]` の http(s) 以外は、**黙って既定へ倒す**。

この値は「利用者のアクセストークンを添えて叩く先」で、緩めると設定を 1 つ
書き換えるだけでトークンが他所へ流れる。ホスト名は完全一致で見る
(`localhost.example.com` のような形を通さないため)。本番の `wrangler.jsonc` には
何も置かない。

### 3. 宛先は引数で渡す (省略できるようにしない)

`gist.ts` / `oauth.ts` は宛先を引数で受け取る。既定値を持たせないのは、**渡し忘れが
「テストのつもりで本物の GitHub を叩いていた」に化ける**のを型で止めるため。
env を読むのは `session/context.ts` の `githubOrigins()` 1 か所に集める。

### 4. 偽 GitHub は知らない口を落とす

実装が新しい GitHub の API を叩き始めたとき、黙って本物へ出ていくのではなく
**テストが落ちて気付ける**ようにする (未対応のパスは 500 + stderr)。資格の無い
要求も 401 で落とす — 本物では「レート制限に化ける」形で静かに壊れるため。

## 影響

- E2E に本物の GitHub アカウントも認可の手作業も要らない。CI でそのまま回る
- 通しで踏めるようになったので、**作品ページだけを見る検証では足りない**ことが分かった。
  作品ページに出るのは R2 の写しで、これは保存要求の中身をそのまま書いたもの。
  Gist に書けていなくても正しく見えるので、正本の確認は偽 GitHub に直接問い合わせる
- `wrangler dev` には `--local-upstream` が要る。routes の `custom_domain`
  (p5stage.org) がローカルのリクエスト URL のホストになり、OAuth の `redirect_uri` が
  本番のドメインになって認可から戻れなくなる
- 偽 GitHub の Gist ID は毎回ランダム。D1 は `--persist-to` で残るので、連番だと
  次の実行が `sketches.gist_id` の UNIQUE 制約にぶつかる
- 本番相当の通し確認 (本物の GitHub アカウントで認可を往復する) は、これで代替されない。
  引き続き人手で行う (Issue #34 の残件)
